# New bake checklist

1. Copy this directory to `content/bakes/<year>/<bake-id>`.
2. Replace every `YYYY` and `bakeXXX` placeholder and fill in `bake.yml`.
3. Run the Abbey media intake workflow and update `photos.yml` with the selected media.
4. Write `story.md`, using `photo` and `gallery` directives.
5. Publish media to create `media-publication.json` and public derivatives.
6. Run `pnpm build`. Validation failures identify the bake and missing field or media reference.

`media-intake.json` is generated by the intake command; the empty file here documents the expected workspace shape.
